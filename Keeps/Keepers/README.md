# Keepers

The keepers screen, which the user reaches by clicking the keepers pile in
the sidebar: the keepers of the done groups, in the same order as the pile,
the latest group's first. `KeepersScreen` shows them as tiles in
`ScrollingTiles`, from Images, so a few keepers fill the window and many
scroll, and the selection moves with clicks and the movement keys. Space or
a double-click shows a full-size view, which fades in over the tiles.
Escape or Space goes back.

It only shows the keepers. The user changes them on the pick screen.

Uses Grouping, Images, Folder, and Keys, and never Sort, Pick, or Done.
