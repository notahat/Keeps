# Pick

The pick screen, where the keepers are picked from one group at a time. It
is being built; see the narrowing plan in PLAN.md. So far this holds
`TileLayout`, the pure, tested layout of a group's photos as an even grid
of tiles, including where the movement keys go within it, and
`PhotoDetailSurface`, a full-window view of one photo that isn't used yet
and will become the pick screen's full-size view.

Uses Grouping, Images, Folder, and Keys, and never Sort.
