# Done

The done screen, shown by clicking the set-aside pile: the done groups,
latest first, each drawn as a pile with how many of its photos were kept.
`DoneScreen` draws them and handles input: clicking selects a group, and
double-clicking or Return opens it on the pick screen, where it can be
changed or marked not done. Arrow keys don't move the selection yet.

Uses Grouping, Images, Folder, and Keys, and never Sort or Pick.
